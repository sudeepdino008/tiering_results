Lookback × Merge Matrix

How the two tiering knobs trade SSD space against execution speed. Each point is one run of 10,000 chaintip blocks from W = 25,400,000 (9mo from W2 = 26,130,000). SSD saved = 1 − SSD commitment GB / all-SSD commitment GB at the same start block (307 GB at W, 380 GB at W2); a negative value means more SSD than all-SSD. You can edit the table cells to try other values.

Trade-off frontier

Each point is one (lookback, merge limit) run. Up and right is better. The connected points are the Pareto frontier: no other run beats them on both axes. The knee of that line is where the conclusion lives.

Trends along each knob

Left column: lookback on the x axis, one line per merge limit. Right column: merge limit on the x axis, one line per lookback. A bend in a line is an inflection worth a sentence in the report.
